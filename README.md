# PulsoTech

Web de tecnología para el deporte: https://www.pulsotech.es

- `articulos/`: artículos en Markdown (la ficha SEO va al principio de cada uno).
- `paginas/`: páginas fijas (Sobre, Contacto, Privacidad).
- `assets/`: estilos e icono.
- `build.py`: genera la web en `docs/`, que es la carpeta que publica GitHub Pages.

Para regenerar: `python3 build.py` (necesita pandoc).
